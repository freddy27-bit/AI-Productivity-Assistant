# AI Workplace Productivity Assistant

## Project Overview
A modern, AI-powered productivity platform built to help professionals 
automate common workplace tasks. This single-page dashboard integrates 
five AI tools into one clean, responsive interface.

Built as part of the AI Skills Acceleration Programme (ASA_6) — CPT Week 6.

## Features
- Smart Email Generator — draft professional emails with tone control
- Meeting Notes Summarizer — extract action items and decisions from raw notes
- AI Task Planner — break goals into prioritised, actionable steps
- AI Research Assistant — structured insights on any topic
- AI Chatbot Interface — interactive workplace assistant with conversation history

## Tools Used
- Lovable AI — app design and build
- Claude AI (Anthropic) — AI responses and prompt engineering
- GitHub — version control and project hosting

## Setup Instructions
1. Click the live app link below
2. Choose any tool from the sidebar navigation
3. Fill in the form fields with your details
4. Click Generate — the AI will produce an editable output
5. Copy, download or refine the result
